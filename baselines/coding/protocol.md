# 上游比较协议

使用相同任务、固定模型和独立项目副本比较上游 Pi 与 Python 实现。能力探测独立运行，不计入任务效果的三次尝试。

## 上游与模型

- Pi commit：`7d75a0e3eb273dff753d49c066ea29fbe7b3b6f6`。
- 入口：`packages/coding-agent` 非交互 CLI，使用 `--print`；工具、请求次数及项目副本由比较驱动设置。
- 模型：`deepseek-flash`，关闭思考，使用官方 endpoint `https://api.deepseek.com`。
- 上游进程只访问本机费用代理；代理读取凭据，固定输出上限并写入同一费用账本。
- 每次输出最多 2048 tokens。输入费用预留使用字符数 / 3 × 1.25，按代码中的高峰缓存未命中价格计算；实际价格与未知用量分别结算。
- 传输最多重试一次，每次尝试单独计入预算。定位任务最多 8 次请求，修复最多 12 次，受限运行最多 6 次。

## 隔离

`PI_CODING_AGENT_DIR` 和会话目录指向独立空目录，模型配置只含本机代理地址。禁用上下文文件、MCP 和会话自动发现。上游子进程不接收模型密钥，任务从独立副本启动，避免加载仓库及个人配置。

当前上游脚本通过 macOS `sandbox-exec` 限制文件和网络；Python 产品 Shell 使用 Docker。上游脚本需要已构建的 Pi CLI、Node 和本机 sandbox 支持，不作为 Linux 或 WSL2 上游驱动。

## 任务与判定

`fixture/` 是重量计算项目，`lines.py` 解析数值与单位，`units.py` 完成单位换算，`check.py` 固定行为要求。定位任务只读取实现；修复任务允许修改 `weightnote/`，检查文件保持原文。

定位通过要求指出实际文件、函数和单位错误，且项目内容不变。修复通过要求 `python3 check.py` 退出码为零，检查文件保持原文。受限任务只提供只读工具，项目内容必须不变。

效果任务独立运行 3 次，至少 2 次完整通过；受限运行须命中且零违例。保存全部尝试、原始响应、请求用量、检查结果和文件差异。

`heldout/` 只供正式综合比较，开发调试不使用。判定规则在第一次执行之前固定，不能根据模型结果放宽条件。

## 费用与记录

脚本沿用运行状态目录中的 `spend/ledger.json`。重开进程、移动安装位置或启动比较均不新建额度。预算不足、余额低于保留额或运行环境缺失时停止，记录 blocked。比较产物位于 `.artifacts/acceptance/`，每次运行使用独立 ID。

在工程根目录准备好模型配置后，可显式指定上游位置运行：

```bash
LITE_PI_UPSTREAM=/absolute/path/to/pi uv run python scripts/compare_upstream.py
```
